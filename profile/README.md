# Semapi

**Stop finding out in production.**

Third-party APIs and platform tools change underneath your code. Semapi watches
the official sources, works out which changes touch the code *you* actually run,
and opens an issue — or a ready-made fix — in your repository before anything breaks.

🌐 **[semapi.progrex.dev](https://semapi.progrex.dev)**

## What it covers

- **SaaS APIs** — Microsoft Graph, Google Workspace, Stripe, Slack, GitHub
- **Platform tools** — Karpenter, KEDA, Kyverno, Istio, Cilium, cert-manager, Terraform providers
- **Observability** — Datadog, Prometheus, Grafana, Loki
- **Your own internal APIs** — from your OpenAPI specs, with a warning on the owner's pull request before a breaking change merges

## How it works

1. **Watch** official changelogs, API specs and Helm charts.
2. **Understand** each change as a structured, risk-scored record.
3. **Match** it against the operations, charts and settings your repositories use.
4. **Deliver** an issue or a pull request, tested by your own CI. Nothing merges without your review.

## Built for teams that care where their code goes

- EU-hosted, including the AI models
- Scans run in your own CI by default; only a list of what your code uses leaves your environment
- Read-only by default; write access only to open alerts and fixes
- Your code is never stored or used for training
